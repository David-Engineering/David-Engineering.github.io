# David Ring Engineering Portfolio

A responsive static website starter for an engineering portfolio with an esports section.

## Preview locally
Open `index.html` in a browser. For a local development server, run `python -m http.server 8000` from this folder and open `http://localhost:8000`.

## Before publishing
- Replace the placeholder email in `index.html`.
- Replace starter project descriptions with your real robotics projects and CAD work.
- The portfolio currently lists VEX Robotics, FIRST Robotics, combat robotics, Onshape, SolidWorks, and the Overwatch details you supplied.
- Add your own photos, CAD renders, skills, and project results.
- Verify that the peak-rank wording and context are clear, and add tournament placements, season/region details, and achievement links if you want.
- Add professional profile links if you want them.
- The current robot/CAD artwork is CSS illustration, not a photograph of your actual work.

## Publishing
This is a static site and can be hosted by GitHub Pages, Netlify, or another static hosting provider.
